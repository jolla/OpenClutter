- **1.2.57** Towers the lidar flight predates keep their height (bug fix, feedback #5, /dev). The lidar height check lowered a model height of 6 m or more that the lidar under the roof read at under 0.6 of it. A tower built after the flight read as whatever stood on its lot, so in Downtown Austin Block 185 (181 m, built 2019 to 2022) came out about 7 m tall from a January 2017 flight, along with Third + Shoal (118.6 m to 15.1 m). A source height of 45 m or more that the lidar reads at under 45% of it is now kept, the same rule the lidar height sample already used. Block 185 exports at 181.1 m. /dev hosts only (export-mode staleTowers); production keeps the old check until the weekly release. Bench: canopy 18-site 75.86, site-type 12-site 65.73, Pismo RV P 96.7 R 89.2 (fills excluded), Fort Wilderness widened JSON 5,796,289 B and JSON plus image 9,661,463 B. The Fly worker is not redeployed, so /dev exports that run there keep the old heights until the next worker deploy.
- **1.2.56** Copy terrain stays on the map (bug fix, feedback #6). Map notes for a tall building just outside the drawn box were written past the edge of the aerial (in Downtown Austin, a 149 m tower 75 m north of the box). In Hamina those notes sat in the grey canvas and the whole terrain paste, GPS points included, landed about 25 m east of the imported map. Notes are now only placed on the map image, so an off-map building no longer takes one of the four tall obstruction slots, and every Copy terrain and GPS paste item is pinned inside the aerial (floor corners that rounded a few centimeters past the edge are pinned to it). The OpenIntent zip is unchanged. Runs on the Fly worker.
- **1.2.54** Place labels on the draw map (/dev). Country, state, city and town names now sit over the aerial, chosen by zoom: states and countries when zoomed out, then cities, then towns. They come from Esri's free World Boundaries and Places reference tiles (no key) and are credited on the map and the data licenses page. They hide from zoom 16 in, the default view, so shop and park names never cover a site while drawing. They never take clicks, sit under the drawn box, and stay quiet if a network blocks them. Labels are on the draw map only: the export image is fetched on the server and has no labels. Export output is unchanged and the Fly worker is not touched.
- **1.2.53** Early block check (/dev). Some company proxies pass GETs but swap every POST for an HTML block page, so a report or an export only failed after the user had typed or waited. Opening Feedback now sends a tiny {"ping":true} POST to /api/feedback; the function answers {ok, ping, configured} without creating an issue, counting toward rate limits, or running the spam checks. If the POST is blocked (dropped connection, timeout, 403, 407, HTML block page, non-JSON reply), the firewall message shows at the top of the dialog right away and Send is greyed out, while the text box stays usable so the text can be copied. A good answer is reused for a minute; a blocked one is checked on each open. Finishing a draw sends the same ping to /api/clutter (answered before any export work) and shows a one-line heads-up if POSTs are blocked; no export starts. Export output is unchanged and the Fly worker is not touched.
- **1.2.52** Shareable links and clear messages when a network blocks the site (/dev). The address bar now follows the map and the drawn box as #map=zoom/lat/lon&box=south,west,north,east, written with replaceState (no Back history) after a 300 ms pause, so a site can be bookmarked or sent to someone. Opening the link restores the view and the box, ready to export; bad values are ignored and clearing the box removes it from the link. Query overrides such as ?areaCap keep working and search text is never in the link. A polygon comes back as its export box. When a company firewall or proxy (Zscaler and similar) blocks a request, the page now says which step was blocked (search, export, export status, download, terrain, tree canopy, map imagery, the map library, or Feedback) and which host, and suggests another network, instead of failing silently. It catches dropped connections, timeouts, 403 and 407, HTML block pages where data was due, and redirects to another host; map tiles show one message, not one per tile. Export, status, download and cancel calls go through one route: if a build points them at a separate API host (window.OPENCLUTTER_API_BASE, unset today) and that host drops the connection, they retry on the page's own /api and stay there for the session; an HTTP answer is never retried elsewhere. A connection the proxy closes now ends Exporting at once with the message instead of sticking, and a last-resort handler turns any stray network rejection into the same message. The Feedback link is now a small pill in the bottom-right corner, Send is greyed out when Feedback cannot be reached, and every failed send suggests another network. Export output is unchanged and the Fly worker is not touched.
- **1.2.51** Feedback form on /dev. - **1.2.38** Cancel stops the export on the server too (/dev page). Before, Cancel on the Exporting button only stopped the page from waiting while the worker ran the job to its end. Production pages do not call the endpoint; exports that are not cancelled are unchanged on every host.
